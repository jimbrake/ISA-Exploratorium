## Variable length BCD (Binary Coded Decimal) processors  
At this time there are two kinds:  
Radix10, e.g. variable length digit at a time, AKA BCD1  
Radix100, e.g. variable length two digits at a time, AKA BCD2  
BCD2 also does radix128 variable length arithmetic  

The BCD_encoding_size paper analyzes the memory efficiency of various ways of storing BCD data for unsigned, signed and floating-point.
